# AI Animation Studio

A comprehensive Next.js application that combines multiple AI-driven animation tools in one platform.

## Features

- **Text to Animation**: Generate animation concepts and previews from text descriptions
- **AI Talking Avatar**: Create speech with synchronized mouth animations
- **Character Animator**: Upload characters and animate them with AI
- **Particle Playground**: Create mesmerizing 3D particle effects

## Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, Three.js, React Three Fiber
- **AI**: OpenAI API (GPT-4, TTS)
- **Deployment**: Vercel
